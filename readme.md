# Buyers Tasks Bot

Телеграм-бот для управления задачами креативщиков. Позволяет создавать, отслеживать и управлять задачами, а также генерировать отчеты в Google Sheets.

## Функционал

### Управление задачами
- ✏️ Создание новых задач
- 📋 Просмотр списка задач
- 🔄 Изменение статусов задач
- 👥 Назначение исполнителей и заказчиков
- ⏰ Установка сроков выполнения

### Отчетность
- 📊 Генерация отчетов в Google Sheets:
  - Задачи в работе
  - Выполненные задачи
  - Полный отчет по всем задачам
- 📥 Массовое обновление статусов через CSV-файл

### Статусы задач
- 🟡 `active` - Активная задача
- 🔵 `progress` - В работе
- 🟣 `wait` - На проверке
- 🟢 `done` - Выполнена
- 🔴 `failed` - Отклонена
- ⚫ `canceled` - Отменена

## Установка и настройка

### Предварительные требования
- Node.js v16+
- MongoDB
- Telegram Bot Token
- Google Cloud Project с включенными API:
  - Google Sheets API
  - Google Drive API

### Шаги установки

1. Клонируйте репозиторий:
bash
git clone [url-репозитория]
cd buyers-tasks-bot

2. Установите зависимости:

```bash
npm install
```

3. Создайте файл `.env` в корневой директории:
```env
BOT_TOKEN=your_telegram_bot_token
MONGODB_URI=your_mongodb_connection_string
```

4. Настройте Google API:
   - Создайте проект в [Google Cloud Console](https://console.cloud.google.com)
   - Включите Google Sheets API и Google Drive API
   - Создайте сервисный аккаунт
   - Скачайте и переименуйте ключ в `credentials.json`
   - Поместите `credentials.json` в корневую директорию

### Запуск

Разработка:
```bash
npm run dev
```

Продакшн:
```bash
npm start
```

## Использование

### Обновление статусов через CSV

1. Выгрузите текущий отчет через бота
2. Измените статусы в колонке "Статус"
3. Сохраните файл в формате CSV
4. Отправьте файл боту через меню "Отправить CSV"

Структура CSV:
```csv
Дата создания,Название,Вид работы,Заказчик,Дата план выдачи,Исполнитель,Статус
19.02.2025,Task_Name,Тип работы,Заказчик,20.02.2025,Исполнитель,done
```

## Зависимости

- `telegraf`: Фреймворк для Telegram бота
- `mongoose`: ODM для MongoDB
- `googleapis`: Google API клиент
- `node-fetch`: HTTP клиент
- `dotenv`: Управление переменными окружения

## Разработка

### Добавление новых команд

1. Создайте обработчик в `src/actions/`
2. Зарегистрируйте команду в `main.js`
3. Добавьте локализацию в `src/lang/ru.json`

### Создание новых отчетов

1. Добавьте функцию экспорта в `src/controllers/task.controller.js`
2. Создайте обработчик в `src/actions/statistics.actions.js`
3. Добавьте кнопку в меню статистики
